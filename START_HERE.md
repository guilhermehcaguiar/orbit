# Orbit — Start Here

Este pacote contém a documentação oficial, identidade visual e arquivos-base do projeto Orbit.

## Como usar com o Codex

1. Extraia este ZIP na raiz do workspace que será usado para desenvolver o Orbit.
2. Dê ao Codex acesso a esta pasta.
3. Envie ao Codex o primeiro prompt fornecido separadamente na conversa.
4. O Codex deve ler primeiro `README.md`, `architecture.json`, a pasta `docs/` e os arquivos de `design/` antes de escrever código.
5. O desenvolvimento deve começar apenas pela fundação do monorepo e pela estrutura arquitetural definida na documentação.
